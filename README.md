# Pong Game 🎮 (Built with Python + Pygame)

This is a simple Pong game created using **Python** and **Pygame**.  
The game includes a bouncing ball and two paddles (left and right).  
Players can control the paddles using keyboard keys.

## 🛠 Requirements
To run this Pong Game, you will need:

1. **Python 3.x** (Tested on Python 3.13)  
   Download Python: https://www.python.org/downloads/
   
3. **PyCharm Community Edition** (Optional but recommended for running/editing the project)
   - You can download it from: https://www.jetbrains.com/pycharm/download/
     
4. Install Pygame package before running the game:
   pip install pygame


## 🚀 Features
- Classic Pong gameplay
- Score system
- Ball collision physics
- Keyboard controls
- Smooth paddle movement

## 🎮 Controls
- **W / S** → Move left paddle (Player 1)
- **Up / Down Arrow** → Move right paddle (Player 2)
